# Security policy

This repository is an independent professional portfolio demonstration. Use synthetic data only in public contributions. Keep credentials, client exports, personal information, and production execution logs outside this repository.

Report vulnerabilities through the repository's Security > Advisories > Report a vulnerability feature when enabled. If unavailable, contact the owner through the GitHub profile before sharing sensitive details. Do not post credentials in a public issue. Only the latest main branch is maintained; there is no production support SLA.
