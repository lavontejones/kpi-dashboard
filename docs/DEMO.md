# Demo walkthrough

1. Run the app with the committed sample CSVs.
2. Compare revenue to the prior year.
3. Select Downside: revenue scales by 0.85 while COGS changes by 80% of that percentage change.
4. Inspect cash coverage and pipeline snapshot.
5. Select North and read the allocation notice.

The SVG preview is generated from the sample CSVs, not a screenshot of the UI.
